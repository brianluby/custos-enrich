# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/brianluby/custos-enrich/security/advisories/new).
Do not open a public issue for a suspected vulnerability. Include affected
versions, impact, reproduction steps, and any suggested mitigation in the
private report.

The maintainers will acknowledge a complete report, assess impact, and
coordinate disclosure and a release when needed.

## Scope

Security reports may include request construction, response validation,
resource-exhaustion risks, TLS configuration, dependency vulnerabilities, or
cases where malformed provider data can be mistaken for trustworthy
prioritization evidence.
